## 关键事实速查（别处没有、易踩的）

- patch 覆盖**逐字段**：`config` 单键整体替换，`disabled` 独立键；同 config 内字段须写全；patch 行 `name` 不匹配目标行 → 整个 patch 被静默跳过
- web seam 无回退链；多 provider 未配 id → `WEB_PROVIDER_AMBIGUOUS`；`available()` 禁止网络请求，回退只能发生在调用失败后
- 兜底 provider 类（`DeepSeekSearchProvider` / `HttpFetchProvider`）可 import 实例化，**绝不注册**（id 冲突 → `WEB_DUPLICATE_PROVIDER`）
- Kenari base URL 两形状：[OI] `https://kenari.id/v1`，Anthropic 不带 `/v1`；错形状报 **405 非 404**
- 价格单位 micro-IDR per 1M tokens；免费模型 = `:free` 后缀或 `pricing.free`；`step-3-7-flash:free` 在 Rp 0 账户可用
- 分享页 key：balance/usage/quota 返 403，spending 工具正常；`web_search`/`web_fetch`/`x_search` 按次真实扣费，失败不计费

完整接口事实在知识库（`docs/knowledge-base/`）：dsh 侧 `dsh/dsh-source-verified.md`（权威性最高）等 4 篇 + `plugin-rules.md` 15 条硬约束；Kenari 侧 `kenari-plugin/kenari-api.md`。改代码前先读，不凭记忆推测。
