  ```js
  ctx.plugin(systemPromptPlugin)                    // dsh-system-prompt（tools 运行时 inject 它）
  ctx.plugin(toolsPlugin)                           // dsh-tools，provide ctx.tools
  ctx.plugin(attachmentPlugin, { dshHome: tmpdir })  // dsh-attachment-local，provide ctx.attachments
  ctx.provide('web', { registerSearchProvider(){}, registerFetchProvider(){} })
  ctx.plugin(kenari, { apiKeyEnv: 'KENARI_API_KEY' })
  await ctx.get('tools').execute({ callId, name, arguments: args, signal })
  ```
  这些包的真实路径在 `/opt/homebrew/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/`
