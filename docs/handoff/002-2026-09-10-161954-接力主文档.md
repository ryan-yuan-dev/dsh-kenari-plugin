## 已验证

真实 key 下：`search_docs`、`list_models`（76 个模型）、`quota`（Studio 套餐窗口）、`count_tokens`、`balance`、`usage`、`x_search`、`ocr`（首次 Rp 75，`reuse_id` 二次 **cost 0**）、`image_generate`、`image_edit`（multipart）、`embed`（1024 维）、`rerank`、`video_generate` + `video_status`。

参数校验逐条触发：handles 互斥 / ≤20 / 字符集、日期格式、OCR 的 file_data 与 reuse_id 互斥、必填项。真实 harness（dsh ToolRuntime + LocalAttachmentStore）派发与图像 attachment 落盘通过。另：dump-config 钉层生效、启动无报错。

## 本期两个改变设计的发现

1. **balance / usage 没有 REST 端点**：`/v1/account/*` 除 quota 外都落到 SPA 首页（返回 200 HTML）。两者改走公开 MCP 端点 `https://kenari.id/mcp` 的 JSON-RPC 无状态调用。
2. **生成类调用 30s 超时不够，且超时不得重试**（服务端可能已完成并计费）。改为 `generationTimeoutMs`（默认 180s）+ `retryTimeouts: false`。
